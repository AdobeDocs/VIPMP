# Marketplace Assistant (Beta)

Marketplace Assistant is an AI-powered conversational assistant available within [Bridge](../index.md). It answers questions about customer accounts, pricing, and renewals using Commerce Partner APIs and Adobe product documentation. It also identifies the sources used for each response so you can verify the information.

 ![Marketplace asisstant home page](<Screenshot 2026-09-15 at 1.46.52 PM.png>)

## How to access Marketplace Assistant chat interface?

Marketplace Assistant is not a standalone application. It is integrated into [Bridge](../index.md) and is available only to partners who already have access to Bridge.

To use Marketplace Assistant, your organization and user account must already be provisioned for Bridge. In addition, your organization's Admin Console administrator must assign the **Marketplace Assistant** role to your account.

See [Getting started](./getting-started.md) for the full access and launch process.

## What can you do with Marketplace Assistant?

Marketplace Assistant currently supports the following capability areas:

- **Customer data**: Account details, order history, and subscription status for a specific customer.
- **Price list**: Pricing, SKU discovery, and discount eligibility, including Three-Year Commit (3YC) pricing.
- **Renewals**: Upcoming renewal status, auto-renewal risk, and explanations for failed or incomplete renewals.
- **VIP Marketplace product knowledge**: General questions about VIP Marketplace features, terms, and processes.

Marketplace Assistant generates responses using either live data from Adobe VIP Marketplace APIs or content from Adobe documentation and knowledge bases. Each response identifies its source so that you can trace the information back to its origin.

Adobe continually expands Marketplace Assistant capabilities. See [Supported features](./supported-features.md) for the latest available capabilities and details about each supported area.

**Important:** Marketplace Assistant responses are AI-generated and may contain inaccuracies. Always verify responses against official Adobe program guides and APIs before taking action.
